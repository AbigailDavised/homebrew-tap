# AbigailDavised Homebrew Tap

Official third-party Homebrew tap for open-source developer utilities and MCP CLI tools.

## Installation

```bash
brew tap AbigailDavised/tap
brew install chineseworksheet-cli
```

## Included Formulas

| Formula | Description | Homepage |
| :--- | :--- | :--- |
| **chineseworksheet-cli** | Chinese handwriting worksheet grid geometry, stroke order rules & HSK analyzer | [chineseworksheet.com](https://chineseworksheet.com) |
